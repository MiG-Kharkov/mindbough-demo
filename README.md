# Mindbough MVP

**Think with AI in branches. Keep the decisions. Use any model.**

**Open it: https://mig-kharkov.github.io/mindbough-demo/**, on a phone too. Menu → **Try a sample conversation** works without an API key.

AI chats force thinking into one feed: its dead ends pollute every answer and the threads you were following get lost, context is forgotten or mixed, every step runs on the same expensive model, and decisions stay locked in one vendor's chat log. Mindbough is an open format for the state of your thinking with AI: the options you explored, the decisions in force, what you remember, and a receipt for every prompt. This app is its MVP: a branching chat that builds every request from that state, and stores each conversation as a Thinking State that you can export and give to an agent.

This repository only hosts the built app on GitHub Pages. CI overwrites it on every change, so don't edit it here. The format, the tools and the app's source are in a repository that stays private until the first public release.
